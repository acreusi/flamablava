# Flama Blava
Primera versió funcional de la botiga web.

## Obrir localment
Obre `index.html` en un navegador modern o serveix aquesta carpeta amb qualsevol servidor estàtic.

## Inclou
- Catàleg de 6 productes de prova
- Carretó funcional en memòria
- Afegir, eliminar i modificar quantitats
- Total del carretó
- Disseny responsive
- Logo de Flama Blava

Aquesta versió encara no inclou pagaments reals, base de dades, comptes d'usuari ni gestió d'estoc.
